# SBO — Frontend

React + Vite client for the SBO platform. Setup, configuration and the overall picture are in
the [main README](../README.md).

```sh
npm install
cp .env.example .env   # VITE_API_URL: where the backend API runs
npm run dev            # http://localhost:5173
npm run build          # production build in dist/
npm run lint           # oxlint
```
